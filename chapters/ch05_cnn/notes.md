## `Conv2d`
- 2d 합성곱
- 이미지 필터처럼 Tensor에 특정 작은 Tensor를 곱해서 연산해서 통과시킴
- 단, 패딩을 추가하지 않으면 작은 Tensor 를 곱하기 위해서 벗어 나는 부분은 손실되며 다음 커널의 크기에 영향을 주고 작아짐
- 만약 28 * 28 데이터에 5 * 5 텐서로 합성곱을 하면, 모서리의 2개씩은 합성곱이 불가능해서 손실처리되고 다음 커널은 24 * 24 로 작아짐
- 이미지 필터와 다르게 결과 채널의 갯수를 늘릴수 있으며, 결과 채널을 늘려서 각각 다른 커널을 가진 데이터로 분리 가능함

### 예시
- 1채널(그레이스케일) 28*28 이미지를 nn.Conv2d(1, 16, 5) 를 통과하게 되면
- 다음에는 16개의 커널(채널)을 가진 24*24 커널을 가짐, 각각 커널은 다른 데이터를 가질 수 있음

## `MaxPool2d`
- `nn.MaxPool2d(2, 2)` 이면 앞에는 kernel_size, 뒤는 stride를 의미함
- 즉 2x2에서 최댓값을 뽑아내며 2칸씩 이동하게 되며, 결과론적으로 2배로 줄어는 다운 샘플링을 하게 됨
- 최댓값만 남겨서 커널에서 특징을 강하게 뽑아내기 위해서 사용됨, 반대로 평균값을 사용하는 `AvgPool2d` 도 있으나 여기서는 각 커널의 특징만 뽑아내기 위해서 사용하지 않음

```
입력 4×4                    출력 2×2
┌───────┬───────┐
│ 1   3 │ 2   0 │
│ 4   2 │ 1   5 │   →     4   5
├───────┼───────┤
│ 0   1 │ 7   2 │         6   7
│ 6   2 │ 3   1 │
└───────┴───────┘
```
