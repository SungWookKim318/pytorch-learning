# 활성화 함수
- 각 층의 `w·x + b` 계산 결과에 씌우는 '비선형 함수'다.
- 없으면 층을 아무리 쌓아도 직선 하나와 같다.
  - `y = 2x + 1`, `z = 3y + 4` → `z = 6x + 7` (다 직선)
- 중간에 비선형 함수를 끼워야 곡선 같은 복잡한 관계를 표현할 수 있다.

## 어디에 쓰나
- 입력층: 없음 (데이터 자체)
- 은닉층: `Linear` 다음에 매번 넣는다
- 출력층: 문제에 따라 다르다
  - 숫자 예측(회귀): 없음. 값의 범위를 제한하면 안 되니까
  - 맞다/아니다 판별: Sigmoid (0–1 확률로 출력)

## 대표적인 활성화 함수
| 이름 | 하는 일 | 출력 범위 | PyTorch |
|---|---|---|---|
| ReLU | 음수는 0, 양수는 그대로 | 0 ~ ∞ | `nn.ReLU()` |
| Sigmoid | 값을 0–1로 눌러 줌 | 0 ~ 1 | `nn.Sigmoid()`, `torch.sigmoid` |
| Tanh | 값을 −1–1로 눌러 줌 | −1 ~ 1 | `nn.Tanh()`, `torch.tanh` |

- 요즘 은닉층에는 계산이 단순하고 학습이 잘 되는 ReLU를 주로 쓴다.

# 역전파 그림 읽는 법
## 값의 흐름
- 값은 왼쪽에서 오른쪽으로 따라가며 값을 넣어서 계산함
- 기울기는 아래의 방법대로, 미분의 체인룰을 활용함
- 자기 자신을 미분하면 1인 점을 이용해서, 역으로 미분하면서 기울기를 구함

## 기울기의 계산
- 제일 오른쪽 에서 왼쪽으로 체인룰을 활용해서 계산함
- 제일 오른쪽은 자기 자신을 미분하게 되니 무조건 `1`이 됨
- 왼쪽으로 이동하면서 오른쪽의 값을 넣어서 미분해서 기울기를 역으로 계속 구함

# 까먹은 미분 관련

## 미분 공식
- x + c 는 1
- 1/x 는 x^-1 이니 -x^-2
- e^x 는 e^x

## 연쇄법칙
dz/dx -> dz/dy * dy/dx 를 활용

## 시그모이드 미분
- 시그모이드 식: `σ(x) = 1 / (1 + e^-x)`
  - 교재 수식의 `σ`와 `sig`는 같은 것 (표준편차 σ, 합 Σ와는 다름)
- 역전파 그림의 오른쪽 노드 네 개를 이은 것이 바로 이 식이다.
  - `x → [*−1] → −x → [exp] → e^-x → [+1] → 1 + e^-x → [1/x] → σ(x)`
- 미분 공식: `σ'(x) = σ(x) × (1 − σ(x))`
  - 안에 `e^x`가 들어 있어서 미분 결과가 깔끔하게 나온다.
  - 순전파 때 구한 σ(x) 값만 있으면 미분값을 바로 구할 수 있다.
- 그림에서 검산: 출력 `0.73` → `0.73 × (1 − 0.73) ≈ 0.20`
  - 노드 네 개를 하나씩 거쳐서 구한 가운데 빨간 값 `0.20`과 같다.
